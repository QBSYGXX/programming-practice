# AlphaGPT-LSTM 量化策略完整解析

## 一、策略概述

AlphaGPT-LSTM 是一款基于**强化学习 + LSTM** 的**截面Alpha因子自动挖掘**策略，运行于聚宽（JoinQuant）回测平台。

**核心思想**：让 AI（LSTM神经网络）像"搭积木"一样，用预定义的运算符和基础特征，自动组合出能预测股票未来收益的截面因子公式，然后在每月初用该因子进行选股调仓。

**策略亮点**：
- 无需人工设计因子，AI 自动探索因子空间
- 逆波兰表达式（RPN）+ 栈式虚拟机，支持任意复杂度的公式嵌套
- 全张量化计算，PyTorch 加速回测
- 严格的防未来函数设计

## 四、模块详解

### 4.1 数据引擎 — `JQCrossSectionDataEngine`

**职责**：将原始行情数据加工成 AI 能"吃"的高质量数学矩阵。

#### 4.1.1 数据获取策略

不依赖基本面接口（避免回测卡死），只用 `get_price` 获取6个基础字段：

| 字段 | 含义 |
|------|------|
| `open` | 开盘价 |
| `close` | 收盘价 |
| `high` | 最高价 |
| `low` | 最低价 |
| `volume` | 成交量 |
| `money` | 成交额 |

然后用这些原始数据"伪造"基本面数据：

```python
# 流通市值替代 → 成交额的60日均值取对数
circulating_market_cap = log(money.rolling(60).mean())

# 换手率替代 → 今日量 / 60日均量 - 1
turnover_ratio = volume / volume.rolling(60).mean() - 1
```

#### 4.1.2 8大基础特征

所有特征从日线数据计算，无需任何基本面接口：

| 特征代号 | 含义 | 计算方式 | 作用 |
|----------|------|----------|------|
| `RET` | 日收益率 | `(close[t] - close[t-1]) / close[t-1]` | 日度涨跌 |
| `RET5` | 5日收益率 | `close.pct_change(5)` | 短期惯性 |
| `VOL_CHG` | 量比 | `volume / volume.rolling(20).mean() - 1` | 资金异动 |
| `V_RET` | 量价共振 | `RET * (VOL_CHG + 1)` | 放量涨跌信号 |
| `TREND` | 趋势强度 | `close / close.rolling(60).mean() - 1` | 多空方向 |
| `LIQUIDITY` | 流动性 | 伪换手率（量/60日均量） | 交易活跃度 |
| `VOLATILITY` | 波动率 | `RET.rolling(20).std()` | 股价稳定性 |
| `SIZE` | 规模因子 | log(成交额60日均值) | 大票/小票 |

#### 4.1.3 数据清洗流水线

```
原始数据 → 前向填充/后向填充缺失值
        → NaN → 0
        → Inf → 0
        → Clip到[-1e6, 1e6]
        → 截面标准化（减去中位数，除以MAD，截断到[-3, 3]）
        → 转为PyTorch Tensor → [8特征 × N股票 × T交易日]
```

#### 4.1.4 预测目标（严格防未来函数）

```python
# 预测：T+1日买入，T+2日卖出的收益率（符合A股T+1规则）
target_ret = (next_next_open - next_open) / next_open
```

### 4.2 AI 模型 — `AlphaGPT`

**职责**：像写作文一样，逐个生成因子公式的符号。

#### 4.2.1 模型架构

```
输入: [上一个Token]
  ↓
Embedding (d_model=64)
  ↓
LSTM (2层, hidden=64, 单向)
  ↓
  ├── Actor Head (fc_actor) → 输出各Token概率 → 采样下一个运算符/特征
  └── Critic Head (fc_critic) → 输出状态价值 → 辅助强化学习训练
```

**为什么用 LSTM？** 因为写公式有上下文依赖。刚写了 `ADD`（加法），下一个词就不该是 `ADD`（加法需要两个操作数，不能连续加空气）。LSTM 的隐藏状态天然记住了已生成序列的上下文。

#### 4.2.2 词汇表

AI 的"语言"由两类词组成：

**名词（8个基础特征）**：`RET`, `RET5`, `VOL_CHG`, `V_RET`, `TREND`, `LIQUIDITY`, `VOLATILITY`, `SIZE`

**动词（13个算子）**：

| 算子 | 参数数 | 含义 | 类别 |
|------|--------|------|------|
| `ADD` | 2 | 加法 | 基础运算 |
| `SUB` | 2 | 减法 | 基础运算 |
| `MUL` | 2 | 乘法 | 基础运算 |
| `DIV` | 2 | 除法（加1e-6防零除） | 基础运算 |
| `NEG` | 1 | 取负 | 基础运算 |
| `ABS` | 1 | 绝对值 | 基础运算 |
| `SIGN` | 1 | 符号函数 | 基础运算 |
| `DELTA5` | 1 | 5日差分 | 时序运算 |
| `MA20` | 1 | 20日均线 | 时序运算 |
| `CS_RANK` | 1 | 截面排序归一化 | 截面运算 |
| `CS_ZSCORE` | 1 | 截面Z-score标准化 | 截面运算 |
| `CS_TOP20` | 1 | 截面前20%标记 | 截面运算 |
| `CS_BOT20` | 1 | 截面后20%标记 | 截面运算 |
| `CS_MOM10` | 1 | 截面10日动量 | 截面运算 |

#### 4.2.3 语法约束（Mask机制）

```python
def get_strict_mask(open_slots, step):
    # 1. 栈已空 → 只能选END（结束）
    mask[done_mask, 0] = 0.0

    # 2. 剩余步数必须填满特征 → 只能选特征
    must_pick_feat = (open_slots >= remaining_steps)
    mask[active_mask, :len(FEATURES)] = 0.0

    # 3. 否则 → 可选特征或算子
    mask[can_pick_op, len(FEATURES):] = 0.0
```

### 4.3 因子挖掘器 — `JQCrossSectionMiner`

**职责**：强化学习训练循环，让 AI 自我进化。

#### 4.3.1 栈式虚拟机 — `solve_one()`

采用逆波兰表达式（RPN）解析，用栈结构执行公式：

```
示例：AI 生成序列 [RET, VOL_CHG, SUB, MA20]

步骤1: 压入 RET 矩阵       → 栈: [RET]
步骤2: 压入 VOL_CHG 矩阵    → 栈: [RET, VOL_CHG]
步骤3: SUB(弹出2个，计算)    → 栈: [RET - VOL_CHG]
步骤4: MA20(弹出1个，平滑)   → 栈: [MA20(RET - VOL_CHG)]

最终因子 = MA20(RET - VOL_CHG)
```

**关键校验**：
- 算子参数不足 → 无效公式，丢弃
- 因子方差 < 1e-4 → 无区分度，丢弃
- 维度不匹配 → 自动对齐或填充

#### 4.3.2 训练流程

```python
for iter in range(30):           # 每月30轮迭代
    1. 采样: 生成64个候选公式（Batch Size）
    2. 筛选: 虚拟机执行 + 语法/方差检查
    3. 回测: 向量化计算每个公式的因子收益
    4. 评分: Sharpe + IR（信息比率）
    5. 更新: Policy Gradient 优化模型权重
```

#### 4.3.3 奖励函数

```python
综合评分 = Sharpe × 15.87                # 夏普比率（年化）
         + IR × 2.0                      # 信息比率（IC均值/IC标准差）
         - 2.0 (如果平均收益为负)          # 惩罚亏损策略
         
# IC计算：因子值与未来收益的截面相关系数
# IR计算：IC的均值 / IC的标准差（衡量因子稳定性）
```

#### 4.3.4 回测模拟（训练集内）

```python
# 截面选股：每期选因子值最大的TopK只
rank = argsort(factor, descending=True)
long_mask = one_hot(top_k indices)
pos = long_mask / top_k  # 等权重

# 换手率惩罚
turnover = abs(pos - pos.shift(1))
port_ret = (pos * target_ret).sum() - turnover.sum() * COST_RATE

# 夏普 = 收益均值 / 收益标准差 × sqrt(252)
sharpe = mean(port_ret) / std(port_ret) * 15.87
```

### 4.4 因子分析 — `cross_section_analysis()`

每月训练完后，对挖掘到的最优因子进行详细诊断：

| 指标 | 含义 |
|------|------|
| **IC均值** | 因子值与未来收益的平均相关系数 |
| **IC标准差** | 相关系数的波动 |
| **信息比率 (IR)** | IC均值 / IC标准差（>0.5为优秀） |
| **IC胜率** | IC > 0的交易日占比 |
| **多空收益** | 按因子分5组，Top组 - Bottom组的收益差 |
| **多空夏普** | 多空收益的年化夏普比率 |

分别在**训练集**（前80%数据）和**测试集**（后20%数据）上计算，判断因子是否过拟合。


## 七、关键技术特点

### 7.1 防未来函数（Look-ahead Bias）
- 训练数据截止到 `context.previous_date`（昨日），绝不使用当日数据
- 预测目标为 T+1 买 → T+2 卖，匹配 A 股 T+1 规则
- 日期匹配使用最近交易日对齐

### 7.2 数值稳定性
- 全局 NaN/Inf → 0 替换
- 截断至 [-1e6, 1e6]
- 除法加 1e-6 防止零除
- 标准差加 1e-6 防止除零
- 因子方差检查（<1e-4 丢弃）

### 7.3 全张量化计算
- 所有特征为 `[N股票, T时间]` 的 PyTorch Tensor
- 回测打分在 GPU/CPU 上批量并行计算
- 一个月的数据加载+训练在数分钟内完成

### 7.4 强化学习设计
- **Actor-Critic 架构**：Actor 生成公式，Critic 评估好坏
- **Policy Gradient**：高分公式的生成路径被强化，低分被抑制
- **语法约束 Mask**：确保 AI 只生成合法公式，提升训练效率

## 八、策略优势与风险

### 优势
1. **自适应**：每月重新训练，因子随市场环境进化
2. **可解释**：输出的是人类可读的数学公式，非黑盒
3. **高效**：全张量化 + 不依赖基本面接口，回测速度快
4. **真实**：完善的风控过滤和成本模拟

### 风险
1. **小市值集中**：20只微盘股，流动性风险大
2. **过拟合**：30轮训练可能拟合噪声，需关注测试集IC
3. **高换手**：每月全部更换持仓，交易成本不可忽视
4. **极端行情**：微盘股在系统性下跌时可能集体跌停无法卖出
5. **策略容量有限**：小市值策略资金容量小，不适合大规模资金
