这是整个策略落地的**最后一公里**。在这个模块，我们不再关心“公式优不优雅”，只关心**“能不能成交”**以及**“会不会亏在摩擦成本上”**。

这部分代码集中在 `initialize`（初始化）、`handle_data`（主循环）以及一系列 `filter_`（过滤）函数中。

我们将它拆解为**“四个卫士”**来理解：

---

### 第一卫士：日历卫士 (The Calendar Guard)

**任务：决定什么时候动手。**

量化交易最忌讳“频繁乱动”。这个策略设定为**月度调仓**。

* **核心代码**：`is_first_trading_day_of_month(context)`
* **逻辑**：
1. 每天开盘，策略都会醒来问：*“今天是这个月的第一个交易日吗？”*
2. 如果是 -> 启动训练，准备调仓。
3. 如果不是 -> 继续睡觉（Pass），保持持仓不动。


* **风控意义**：
* 降低**换手率**。对于 Alpha 类策略，频繁交易意味着手续费会吃光利润。一个月动一次是比较平衡的节奏。
* 确保**数据窗口完整**。月初正好拿满上个月的完整数据进行训练。



---

### 第二卫士：合规卫士 (The Compliance Mesh)

**任务：把“脏”股票剔除出去。**

在选出 Top 20 股票之前，必须经过层层筛网。代码中实现了一系列 `filter` 函数：

| 过滤网 | 代码函数 | 为什么过滤？ |
| --- | --- | --- |
| **剔除科创/北交** | `filter_kcbj_stock` | 门槛高，波动规则不同（20%/30%涨跌幅），干扰模型。 |
| **剔除 ST/退市** | `filter_st_stock` | **防踩雷**。ST 股随时可能退市，流动性枯竭，量化策略的噩梦。 |
| **剔除停牌** | `filter_paused_stock` | 停牌了买不进也卖不出，必须剔除。 |
| **剔除次新股** | `filter_new_stock` | 上市不满 90 天。新股波动无规律，且数据太少，容易把 AI 带偏。 |

**高光细节**：

* **涨跌停过滤** (`filter_limitup_stock` / `filter_limitdown_stock`)
* 这非常关键！回测引擎通常默认你可以按收盘价买入。但现实中，**如果股票涨停了，你是买不进去的**；**如果跌停了，你是卖不掉的**。
* 代码显式检查了 `current_price` 是否等于 `high_limit` 或 `low_limit`，防止了“回测一直赚，实盘买不进”的假象。



---

### 第三卫士：时空卫士 (The Time Master)

**任务：防止“偷看答案” (Look-ahead Bias)。**

这是所有量化新手的坟墓，但这份代码处理得很专业。

* **核心逻辑**：
```python
end_date = context.previous_date  # 明确使用昨日
start_date = end_date - pd.DateOffset(months=12)

```


* **场景模拟**：
* 假设今天是 **11月1日**（交易日）。
* 策略在开盘前运行。
* **数据截止**：它只能看到 **10月31日** 收盘前的数据。
* **动作**：用截至 10月31日 的数据训练出因子，然后在 11月1日 开盘后进行买卖。


* **意义**：严格实现了**“T日训练，T+1日交易”**。如果用了 `context.current_dt`（今天）的数据去训练然后今天买，就是作弊（因为你买入的时候今天的收盘价还没出来）。

---

### 第四卫士：成本卫士 (The Cost Simulator)

**任务：模拟真实的“疼痛”。**

回测里最容易产生幻觉的就是忽略成本。代码在 `initialize` 里下了重手：

1. **手续费 (Commission)**：
```python
set_order_cost(OrderCost(close_tax=0.001, ...))

```


* 卖出收 0.1% 印花税，买卖双向收 0.03% 佣金。这符合 A 股实情。


2. **滑点 (Slippage) —— 重点！**
```python
set_slippage(PriceRelatedSlippage(0.002))

```


* **设定**：0.2% 的价格滑点。
* **含义**：你想 10.00 元买入，实际上系统会按 10.02 元给你成交。你想 10.00 元卖出，实际按 9.98 元成交。
* **针对性**：因为这个策略专门买**微盘股**（市值最小的20只）。微盘股流动性差，买单一下去价格就飞了。**0.2% 的滑点设置是对微盘股策略真实性的最低尊重。**

### 交易执行流程图 (Flowchart)

这一套组合拳打下来，每月的调仓动作是这样的：

1. **Check 1**: 是月初吗？ -> YES。
2. **Select**: 拿中小综指所有股票，按市值排序，取最小的 20 个。
3. **Filter**: 把 ST、停牌、涨停的踢掉，剩下的作为 `Target_List`。
4. **Sell (卖出)**:
* 检查现有持仓。
* 如果某只股票不在 `Target_List` 里 -> **卖出**。
* *风控检查*：它跌停了吗？跌停就别卖了，挂着吧。


5. **Buy (买入)**:
* 计算每只票买多少钱（等权重，1/N）。
* 对 `Target_List` 里的股票 -> **买入**。
* *风控检查*：它涨停了吗？涨停就别挂单了，浪费时间。
